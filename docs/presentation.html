1. 專題名稱、使用對象與想解決的問題

專題名稱：LINE Bot AI 智慧助理（多輪對話記憶與雲端部署改善版）

🎯 專題定位與使用對象

  • 使用對象：學生、上班族、一般 LINE 通訊軟體用戶。
  • 應用場景：隨手查資料、日常諮詢、寫作與翻譯，免裝額外 App。

💡 想解決的核心問題

  • 痛點 1（便利性）：傳統 AI 需切換專用 App 或網頁，整合進 LINE 最直覺。
  • 痛點 2（第一版斷裂）：第一版為無狀態單次呼叫，無法記住前文代名詞。

🚀 改善版的核心目標

升級為 Gemini Chat API 多輪對話記憶，依 LINE user_id 獨立隔離對話 Session，並提供完善的防呆提示與 Render 24 小時雲端部署！

開發者：VIKYEH ｜ GitHub: github.com/VIKYEH/hello-python 1 / 5

2. 核心功能與對話範例

結合 Google Gemini 3.7 Flash 大腦與 LINE SDK v3 模組化架構

🤖 核心功能特色

  • 上下文記憶：能理解「那裡、他、這件事」等前文代名詞。
  • 個人隔離 Session：每位好友擁有獨立記憶空間，互不混淆。
  • 快捷系統指令：/help、/time、/ping 秒回不耗額度。
  • /reset 重設記憶：隨時清除記憶重啟話題。

📱 真實對話範例

用戶：你好！我叫做小宇，我住在台北。
AI：嗨小宇！很高興認識你！台北很棒呢！😊
用戶：你知道我剛剛說我住哪裡嗎？
AI：當然！你剛說你住在台北！🏙️
用戶：/reset
AI：🔄 對話記憶已清除，我們重新開始吧！

4. AI 如何協助，以及如何檢查與修正

說明 AI Agent 工具使用歷程與關鍵除錯真實經驗

🛠️ AI 協助的環節

運用 Antigravity AI Agent 進行架構規畫、撰寫 line-bot-sdk v3 數位簽章驗證、建立 pytest 自動化測試，並快速產出多輪記憶核心模組。

🔍 真實檢查與修正 AI 產出的經驗

  • 問題發生：AI 原先引導使用的 Gemini 模型名稱因 Google 近期更新已淘汰，呼叫時遭遇 404 NOT_FOUND；切換模型後又遇上高流量的 503 UNAVAILABLE 尖峰。
  • 檢查與修正：我主動檢查 API 回傳錯誤日誌，指揮 AI 呼叫 client.models.list() 檢索實際可用的模型清單，最終鎖定 gemini-3.7-flash，並建立三層模型平滑降級備援機制（3.7-flash → 3.5-flash → 3.8-flash），徹底解決模型斷線風險！
