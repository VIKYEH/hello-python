📌 一、專題介紹

🎯 專案定位：打造個人隨身攜帶、全年無休的 LINE AI 智慧生活助理。
  • 用途：解決日常生活中臨時查資料、寫作發想、翻譯、即時諮詢等需求，無需另外下載 App，直接在最熟悉的 LINE 聊天室中獲取高品質 AI 回覆。
  • 使用對象：學生、上班族、一般 LINE 通訊軟體用戶，以及任何需要即時 AI 問答的個人使用者。
  • 核心功能：
    • Google Gemini 智慧多輪對話：支援前後文理解與代名詞推導，能進行深度自然對話。
    • 獨立使用者 Session 隔離：每位好友擁有獨立記憶空間，聊天紀錄互不干擾。
    • 完整快捷指令系統：/help（功能清單）、/time（伺服器時間）、/ping（連線檢測）、/reset（清除記憶重啟話題）。
    • 完善防呆防護：自動過濾空白輸入、對不支援指令提供清晰指引。
    • 24 小時雲端在線：部署於 Render 雲端平台，具備安全 HMAC 數位簽章驗證防護。

🛠️ 三、開發過程紀錄

  1. 計畫構思：規劃採用 LINE Messaging API v3 + Flask + Gemini 3.7 Flash + Render 雲端部署架構，撰寫詳細計畫檔案。
  2. 第一版開發 (v1.0)：
    • 建立 app.py、config.py、.env.example，實作 X-Line-Signature HMAC 簽章驗證。
    • 加入 /help、/time、/ping 與基礎 Gemini API 呼叫。
    • 成功推送 GitHub 並通過 Render 部署，完成 LINE 官方 Webhook 驗證。
  3. 發現問題與改善 (v2.0)：
    • 發現 v1.0 為無狀態單次呼叫，AI 無法記住前文代名詞。
    • 改用 Gemini Chat Session 實作多輪記憶，依 LINE user_id 隔離不同用戶。
    • 新增 /reset 指令，並強化輸入不完整（空白）與不支援指令的防呆提示。
  4. 測試驗證：撰寫 pytest 單元測試（6/6 全數通過），並在手機 LINE 上進行三大情境實測。

🤖 四、AI 協作紀錄與修正經驗

  • 使用的 AI 工具：Antigravity Agentic Assistant (Google DeepMind)、Gemini 3.7 Flash API。
  • 代表性指令（Prompt）範例： 
    請依照我的 LINE Bot 專案，為其升級多輪對話記憶功能：
1. 改用 Gemini Chat API (client.chats.create)
2. 依據 LINE user_id 建立獨立 Session 避免不同好友對話混淆
3. 新增 /reset 指令讓使用者能隨時清除對話記憶
4. 針對空白訊息與未知指令提供清晰防呆提示
  • 檢查與修正 AI 產出的真實經驗：
    🔍 真實檢查與修正案例：
    在串接 Google GenAI 模組時，AI 最初推薦使用已淘汰的模型名稱，導致連線時回傳 404 NOT_FOUND: model is no longer available；隨後在呼叫高負載模型時又遇到了短暫的 503 UNAVAILABLE 流量尖峰。
    我的檢查與修正：經由即時分析錯誤代碼，指導 AI 查詢目前真正支援的可用模型清單，最終確認並鎖定最新的 gemini-3.7-flash，同時在 ai_service.py 中加入多模型平滑降級備援機制（3.7-flash → 3.5-flash → 3.8-flash）與例外捕獲，使系統不再因 Google 伺服器短暫波動而崩潰！

✨ 改善版重點紀錄（原本問題、修改、前後差異）

1. 原本的問題 (v1.0)： 第一版為無狀態架構（Stateless）。使用者問完問題後，下一句若提及「那裡、他、這件事」等代名詞，AI 完全無法辨識前文背景，對話頻繁斷裂。此外，若使用者誤傳空白訊息或輸入未知指令，系統缺乏明確提示。
2. 修改內容 (v2.0)：
  • 重構 handlers/ai_service.py：改用 client.chats.create()，建立 _chat_sessions 字典儲存每位使用者的對話 Session。
  • 更新 handlers/message_handler.py：提取 event.source.user_id 實現個別使用者隔離；新增 /reset 重設記憶指令。
  • 防呆機制升級：空白訊息提醒補充文字；非支援指令列出可用指令選單。

3. 改善前後差異對照表

比較項目 第一版 (v1.0) 改善後版本 (v2.0)

💡 六、心得與已知限制

  • 學習心得：
    • 深入掌握了 LINE Messaging API v3 的安全驗證機制（HMAC 數位簽章）。
    • 學會如何將無狀態的 Webhook 伺服器結合 Chat API 實作具備記憶能力的智慧對話系統。
    • 體驗了現代化 CI/CD 流程：透過 Git 推送至 GitHub，觸發 Render 雲端自動建置與無伺服器部署。
  • 已知限制與未來改善方向：
    • 記憶生命週期：目前的 Session 記憶儲存於伺服器記憶體中，若 Render 伺服器重新開機（或休眠重啟），歷史記憶將會重置。未來可規劃串接 Redis 或 PostgreSQL 資料庫進行持久化儲存。
    • 免費雲端冷啟動延遲：Render 免費方案在閒置 15 分鐘後會進入休眠，第一次喚醒時約需等待 30 秒。
